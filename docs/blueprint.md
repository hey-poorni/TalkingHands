# **App Name**: Talking Hands

## Core Features:

- Live Video Feed: Display the user's live video feed for sign language interpretation.
- Real-time Text Translation: Translate sign language gestures into text in real-time, displaying detected alphabets and words.
- Floating Caption Overlay: Show spoken words from other participants as a floating caption overlay on the video feed.
- 3D Virtual Hand Avatar: Generate sign gestures from spoken words as a tool, performed by a 3D virtual hand or avatar.
- Voice Output Toggle: Allow the user to toggle voice output for translated text.
- Emoji Reactions: Enable users to send emoji reactions during the meeting.
- AI Assistant: Integrate an AI assistant to summarize the conversation or perform other helpful tasks.
- Landing Page: A marketing landing page to explain the application

## Style Guidelines:

- Primary color: Soft violet (#A094FF) for a futuristic and calming feel.
- Background color: Light teal (#E0F2F7), desaturated to provide a calming effect and reduce eye strain during extended use.
- Accent color: Electric blue (#7DF9FF) to highlight interactive elements and indicate active translation.
- Body and headline font: 'Poppins', a geometric sans-serif font that maintains a precise and friendly look, balancing approachability with contemporary design.
- Use futuristic icons with a neon glow effect for hands, waves, microphone, and captions, symbolizing advanced technology and accessibility.
- Design the layout with rounded cards, depth shadows, and animated light trails to provide an accessible and elegant interface.
- Incorporate smooth, glowing animations for text translation and subtle motion for UI elements, creating a tech-forward and engaging user experience.
